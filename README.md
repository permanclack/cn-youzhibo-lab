# cn-youzhibo-lab

这是一个用于归档和发布多个独立 HTML 页面的仓库。仓库中的页面内容以静态 HTML 文件形式存储，不针对任何特定网站或域名。

## 项目简介

本仓库旨在提供一个干净、简单的空间，用于存放和展示各类独立的 HTML 页面。这些页面可能包含工具、演示、实验性项目或其他静态内容。仓库本身不提供任何形式的营销、推广或商业服务。

## 目录说明

仓库根目录下按功能或主题划分文件夹，每个文件夹内包含一个或多个独立的 HTML 文件。建议的目录结构如下：

```
cn-youzhibo-lab/
├── README.md          # 本说明文件
├── page-a/            # 示例页面目录
│   ├── index.html
│   └── ...
├── page-b/
│   ├── index.html
│   └── ...
└── ...
```

每个 HTML 页面均为自包含文件，可独立运行，无需额外依赖（除非页面内明确引用外部资源）。
